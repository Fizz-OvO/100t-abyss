1. 構成コンセプト（ジェット＋フェニックス構成）

  • 100 Thieves Abyss comp（ジェット＋フェニックス構成）
  • Timotino = Jett（ジェット）／ Asuna = Phoenix（フェニックス）／ vora = Sova（ソーヴァ）／ bang = Harbor（ハーバー）／ Cryocells = Cypher（サイファー）
  • 2デュエリスト＋1イニシエーター＋1コントローラー＋1センチネル。Champions 2026とAmericas Stage 2で使われた全2試合・34ラウンドが対象（この構成のAbyss使用は両大会＋EMEA／Pacific Stage 2を通じても100Tのみ）
  • 戦績は1勝1敗（G2 5-13／NRG 13-3）、ラウンドは 18勝16敗（52.9%）。攻撃 13勝11敗（54.2%） ／ 防衛 5勝5敗（50.0%）。ただし試合ごとの差が大きく、NRG戦は攻撃9勝3敗・防衛4勝0敗、G2戦は攻撃4勝8敗・防衛1勝5敗と真逆の内容
  • 数値出典: vlr.gg＋vreplay映像解析（勝敗は全34ラウンドでvlrと一致を検証済み）。GIFは34ラウンド全件あり

強み

  • デュエリスト2人がFBを量産する
  • → FB取得は全34ラウンド中21ラウンドで、内訳は Timotino 9回・Asuna 7回・bang 3回・vora 2回。エントリー役の2人で16回と大半を占める
  • → FBを取ったラウンドは 14勝7敗（66.7%）と変換率も高い
  • 攻撃の設置到達率が高い
  • → 攻撃24ラウンド中18ラウンド（75%）で設置に成功。主戦場はA 13・B 11とほぼ均等で、片寄せしない攻め
  • → A設置は 6勝3敗（66.7%、9回）と取り切りが良い
  • 速いヒットが機能する試合がある
  • → NRG戦の勝因タグは「初動Aファイト勝ち」6件・「ラッシュ」5件・「トレード勝ち」7件。初動の当たりで押し切る形がこの構成の勝ちパターン
  • AsunaのULTをエントリーに使う
  • → Asuna（Phoenix）のラン・イット・バックは攻撃ラウンドで繰り返し使用され、G2戦R6ではbangのレコニングと同ラウンドで重ねて勝利。ULT合わせの攻めは型セクション参照

弱み

  • B設置後に守れない
  • → B設置は 3勝6敗（33.3%、9回）で、G2戦に限ると1勝5敗。敗因タグでも相手の「リテイク」が目立ち、設置後の配置・時間の使い方が最大の課題
  • → A設置（{_p(plants_a)}）との差がそのまま構成の弱点になっている
  • FBを落とすと崩れる（特に格上相手）
  • → FBを落としたラウンドは 4勝9敗（30.8%、13ラウンド）。G2戦ではFB喪失ラウンドが 0勝8敗と全敗で、先に1人落ちた後の立て直しができなかった
  • 防衛が試合で真逆になる
  • → 防衛は合計 5勝5敗だが内訳はNRG戦 4勝0敗／G2戦 1勝5敗。防衛ラウンド自体が10しかなく、安定した形とは言えない（下記の配置実測も少数観測）
  • ピストルは互角
  • → ピストルラウンドは 2勝2敗（攻撃 0勝2敗／防衛 2勝0敗）

防衛の配置（実測・少数観測）

  • 固定アンカーは確認できなかった（実測）
  • → 防衛10ラウンドの開始時点（1:40）の検出ベース実測。サンプルが少なく、他チームのプレイブックのような固定配置は断定できない
  • → Cryocells（Cypher）: A 4回／B 5回（n=9）と試合で担当側が変わる。G2戦はA寄り、NRG戦はB寄りで検出
  • → bang（Harbor）: A 4回／B 2回／Mid 1回（n=7）、vora（Sova）: A 3回／B 2回／Mid 3回（n=8）と分散
  • → ※ 図解はTactiValで後日追加

攻撃の形（実測）

  • 両サイト均等＋設置まで行く攻め
  • → 主戦場はA 13ラウンド・B 11ラウンド、設置もA 9回・B 9回と均等
  • → 勝敗を分けるのは「入れるかどうか」ではなく「設置後に守れるかどうか」（A {_p(plants_a)} vs B {_p(plants_b)}）
  • 攻撃の初期配置は実測不可
  • → 放送ミニマップの仕様で攻撃側の選手アイコンが表示されず、選手単位の初期配置は測定できない。デフォルトの形はGIFの動きからの推定になるため、ここでは断定しない
  • ラッシュとULT合わせ
  • → 勝因判定に「ラッシュ」を含む攻撃ラウンドは 6件、「ULT」を含む攻撃ラウンドは 8件（各セクションに勝敗を掲載）
